Release signing key

Every release is signed with one Ed25519 key that we keep offline. Before you trust a download, check that this fingerprint matches the one in the public repository's README. This page and the README are two separate places, so a change to one would show up as a mismatch.

The full key, as the allowed_signers line that OpenSSH uses to check a signature:

If we ever replace the key, the new one will be announced here and in the README, and signed by this one.

Download and check it

These commands download the release, show the key's fingerprint so you can compare it with the one above, then check the signature and the hash. The quickstart takes it from there: install, run the demo, check the evidence.

sudo apt-get update && sudo apt-get install -y bubblewrap python3 systemd dbus-user-session openssh-client wget
mkdir -p ~/cybercircuit && cd ~/cybercircuit
V=0.1.0-eval.4; R=https://github.com/amitb-quantum/cybercircuit/releases/download/v$V
wget -q $R/cybercircuit-$V-x86_64-linux-musl.tar.gz $R/SHA256SUMS $R/SHA256SUMS.sig
wget -q https://raw.githubusercontent.com/amitb-quantum/cybercircuit/main/allowed_signers
cut -d' ' -f3,4 allowed_signers | ssh-keygen -lf -
ssh-keygen -Y verify -f allowed_signers -I release@cybercircuit.ai -n cybercircuit-release -s SHA256SUMS.sig < SHA256SUMS
sha256sum -c SHA256SUMS

You should see the fingerprint above, then Good "cybercircuit-release" signature, then OK for the tarball. If any of the three differs, stop and tell us.

Before you rely on it

Limits of this release
  • Linux on x86_64 only, and only the three systems above have been tested.
  • Run it on a test machine or VM first. The agent can change anything in the workspace you give it.
  • Receipts stay on the same machine unless you set up off-host delivery. The public transparency log shown on Lab results is not configured by the quickstart.
  • The post-quantum signature library is a pinned pre-release that has not been independently audited.
  • An evidence bundle shows what the gateway recorded and signed. It is not proof of compliance.
