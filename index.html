Agents act faster than anyone can watch them

A coding agent with tool access can call APIs, change repositories, and spend credentials in seconds. Guardrails that judge intent with another model can be argued with. Rate limits forget: they slow an agent down, then let it carry on.

Cyber-Circuit is narrower and firmer.

Authority is granted up front in a trusted config, and the agent can only end up with less of it, never more. Whether a call is allowed is decided by fixed policy. No language model sits in that path.

What happens when an agent goes too far

  1. Grant

    Each tool gets a quota and an expiry in a trusted config. The agent gets one-use leases against that quota, never the config itself.

  2. Check

    Every tool call goes through the gateway. It runs only if the policy allows it and the decision has been written to the journal first.

  3. Trip

    The breaker trips on an exhausted quota, a burst of denied calls, a caller the gateway doesn't recognize, a journal write failure, or an operator's command.

  4. Kill

    The gateway quarantines itself, then kills every process in the agent's scope. The kill only counts once the system confirms the scope has stopped.

  5. Alarm

    Your notifier script receives the event as JSON. Whether it was delivered, failed, or timed out is recorded, and a failed alarm never undoes the trip.

  6. Reset

    A restart doesn't clear a trip. An operator does, with a written reason, before an agent is attached again. Spent quota is not refunded.

What we don't claim

These limits are the ones the software actually has today. We'd rather publish them than have you find them in production.

Evidence boundary
  • Finding rogue agents elsewhere on your network. Cyber-Circuit watches the boundary it owns, and records anything that touches the gateway.
  • Protection against a compromised host, root user, or kernel.
  • Detecting deletion of records written after the last signed checkpoint left the machine. Edits are always caught, and deletions are caught once a checkpoint covering them has been sent out.
  • A separately authenticated operator. Today, reset authority belongs to the user account the gateway runs as.
  • Windows, macOS, or more than one agent per gateway.
  • Results beyond what we tested: one machine, one agent version, one tool server, and bypass attempts we listed in advance, not an exhaustive attack.
  • Control over what the agent sends the model. Its workspace and its prompts are still ways data can leave.
